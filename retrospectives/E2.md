# E2 retrospective · Authentication and profile

2026-10-14 → 2026-10-19 · `v0.2.0` · held 2026-10-19

## User feedback

- The token savings agreed in the E1 retrospective did not materialise: QA spent more tokens than before.
- Decision: QA is removed completely, together with other changes to improve token usage (already applied).
- Pending from E1: convert the agent workflow to Claude Code workflows (https://code.claude.com/docs/en/workflows).

## Decisions

- **Keep the current approach (subagents driven by the PM) for E3** and observe how it behaves with the changes above.
- **Claude Code workflows are explored in the E3 retrospective.** Notes for that discussion: a workflow script keeps intermediate results out of the PM context and codifies the review loop, but it does not reduce total tokens (built for large fan-outs; our pipeline is ~5 sequential agents), takes no mid-run user input (the 👤 checkpoints would be separate runs), and a resume replays every agent after a failure. Open question: whether a script can invoke the `.claude/agents/` definitions. Suggested trial: only the develop-and-test loop, `small` size guideline, compared against the T-041 numbers (31 min).
- UI refinements from Checkpoint E2-B were deferred to the E8 backlog (PR #63).
