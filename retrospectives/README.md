# Retrospectives

One file per epic (`E1.md`, `E2.md`, …), written by the PM with the user right after the epic is approved and tagged. Each records the numbers, what worked, what did not and the rule each lesson became. Durable lessons become rules in `CLAUDE.md` ("Working rules") or in `.claude/agents/`; these files keep the history and context behind them and are not pruned.
