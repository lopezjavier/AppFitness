# T-277 Audit, Run B (backend: SQL, pgTAP, Edge Functions, old-app impact)

**Verdict (free text): no coach logic reads free text. No STOP.** The text reaches the `coach` function only as a passenger inside the `coach_summary` jsonb (key `free_text`); nothing in `supabase/functions/` reads it (Grep `free_?text|freeText` over `supabase/functions` = 1 hit, `coach/planNutrition.test.ts:522`, a fixture field inside the test "free text in the summary never changes a figure", which asserts that a summary carrying `free_text` yields the same `nutrition` as one without). Every kind in `coach/router.ts` is deterministic ("no model call", ADR-103); the `coach` function has no Gemini/fetch call (Grep `gemini|fetch\(` over `supabase/functions/coach/*.ts` non-test = 0). `exercise-chat` reads no note/summary/intake (Grep `note|free|summary|intake|check_in|discomfort` over its non-test files = 0).

One thing the PM should know (not a computation, not outbound): `coach/plan*.ts` pass the whole `coach_summary` as `inputSummary` and `index.ts` stores it with `p_input_summary` in `coach_recommendations.input_summary` (jsonb, audit snapshot). So existing production rows in that column contain `free_text` copies. Dropping the key from `coach_summary` stops new copies; old snapshots keep the key and nothing reads it (harmless; scrubbing them is optional and is a production-data UPDATE, so it needs the user's call).

**Methods and limits.** Docker was down, so no `db reset`: inventory derived by script over `supabase/migrations/*.sql` in order (last `create [or replace]`/`drop` per function wins): 201 distinct functions created, 14 net-dropped, 187 live in `public` (plus triggers). Name counting was done with a word-token count over `git ls-files`-listed sources (app main, app tests, supabase/functions, migrations, pgTAP); a caller graph was built from the last definition body of each function, so functions rewritten by `pg_temp.patch_fn` text patches (20270110, 20270126) can show a missing caller: rows marked "verify" below. Old-app impact: tag `v1.9.0` = `3f3207fd`; `git diff --stat v1.9.0 HEAD` touches only docs (planning/, tasks/, retrospectives/), so app code at HEAD equals v1.9.0 and "old-app" = "current app" for every row. Dynamic-use check on every row: RPC names in the app are literals (`postgrest.rpc("name"`) or `const val` names (e.g. `DELETE_FUNCTION`), all found by the word search; Edge Function names are literals in `invoke("...")`; `coach` kinds are the five literals `plan_nutrition|plan_recompute|plan_diet_break|plan_phase_change|plan_goal_switch`, all in `router.ts`. Not done: an exhaustive column-by-column pass (see "Not covered").
